### 1.4 이번 변경에서 특히 볼 것

- **다크 `primary-foreground` 변경 (계획에 없음)**: 다크 기본 버튼 글자를 차콜에서 초록(`pine-950`)으로 바꿨다. 대비와 의도(초록 바탕과 통일)가 맞는지, phase 문서에 기록이 필요한지 판단한다.
- **"시작하기" 브랜드 버튼에 동작이 없다**: 예시용이지만 사용자가 누를 수 있는 버튼이 아무 일도 하지 않는다. 예시로 둘지, 비활성/설명 처리할지 판단한다.
- **`brand-ink`와 `brand`가 다크에서 같은 값**(`wood-300`)이다. 의도한 것인지 문서와 일치하는지 확인한다.
- **폰트 로딩 비용**: Nanum Gothic Coding은 한글 폰트라 용량이 크다. 짧은 문구에만 쓰는데 모든 페이지에서 불러온다. `display=swap`이라 화면은 막지 않지만 기록해 둘지 판단한다.
- **`.dark`의 선 색**: `rgb(255 254 241 / …)`로 cream-50 새 값에 맞춰 바뀌었는지 확인한다.
- **문서 안의 이전 값 잔재**: `#FFFEF2`, `#F6F5E8`, `#CA432F`, `#1F1F1D`, `ink-` 같은 이전 값이 결정 기록 외에 남아 있지 않은지 확인한다.
