### 1.4 이번 변경에서 특히 볼 것

- **계획과 다른 캐시 방식**: `pnpm/action-setup`의 캐시를 쓰도록 바꾼 이유가 타당한지, 실제로 캐시가 동작하는지(실행 기록의 post 단계) 확인한다.
- **필수 승인 0과 "리뷰 대화 해결 필수"의 조합**: 승인 없이도 머지되지만, 댓글이 해결되지 않으면 막힌다. 의도와 맞는지 확인한다.
- **`main`이 빈 커밋 하나뿐이라 생기는 문제**: PR 템플릿과 Dependabot 설정은 `main`에 들어가야 동작한다. PR #5 머지 전까지는 확인할 수 없다는 점을 기록한다.
- **ruleset `do_not_enforce_on_create: false`**: 새 브랜치를 만들 때는 영향이 없는지(대상이 `main`뿐이라 해당 없음) 확인한다.
- **관리자 우회 없음**: 긴급할 때 ruleset을 끄는 방법과 기록 규칙이 문서에 있는지 확인한다.
