### 1.4 이번 변경에서 특히 볼 것

- **CI의 git**: `--remerge-diff`는 git 2.36부터다. PR #44 CI 로그의 git 버전. 이 PR에는 머지 커밋이 없어서 CI에서 `--remerge-diff`가 실제로 불리지는 않는다 (확인 못 함 후보).
- **`--remerge-diff --name-only` 출력**: 파일 이름만 나오는지, 충돌 표시나 머리말 줄이 섞이지 않는지. 이름을 바꾼 파일, 지운 파일의 충돌.
- **커밋 순서**: `--parents`를 붙여도 `rev-list --reverse` 순서가 `--no-merges` 때와 같은지 (머지가 아닌 커밋끼리의 순서).
- **검사 4**: 첫 커밋이 머지여도 "코드를 바꾼 첫 커밋"이 머지가 아닌 커밋으로 잡히는지 (테스트 하나).
- **검사 6의 리뷰 문서 쪽**: 충돌을 풀며 리뷰 문서를 고친 머지도 "리뷰 문서를 바꾼 커밋"으로 잡힌다. 의도에 맞는지.
- **`main()` 로그**: 커밋 수에 머지가 포함되면서 숫자가 지난 로그와 달라지는 것이 혼동을 주지 않는지 ("그중 머지 N개").
- **phase 17 기록**: 17 문서·17 리뷰 문서에 적은 머지 뒤 결과(`5817ee4`, `diegesis-fe-5817ee4-ba9b03`)가 `gcloud`와 같은지.
