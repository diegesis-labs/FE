### 1.4 이번 변경에서 특히 볼 것

- **옛 쪽 표를 잠깐 쓰는 것:** 글꼴만 바뀌면 다시 잴 때까지 옛 표를 쓴다. 다시 재는 것은 같은 커밋의 ref 콜백이라 화면에는 새 표만 그려져야 한다. 글자 폭이 실제로 바뀌어 표가 달라졌을 때도 넘긴 쪽(`turned.page`)은 `layoutKey`가 다르므로 쓰이지 않고 기준 문장으로 다시 찾는지.
- **`viewKey`의 범위:** 쪽 크기만 담고 글꼴 횟수는 뺐다. 크기 변경에서는 미끄러짐이 꺼지는지 (완료 기준 6).
- **렌더 중 `setTurned(null)`:** 다른 챕터로 위치가 바뀐 렌더에서 한 번만 불리는지 (무한 렌더 없음).
- **미리 받는 글자 수:** 챕터 다섯 개(지금 + 앞뒤 2)의 본문을 렌더마다 이어 붙이고 중복을 뺀다. 렌더가 잦은 곳(끌기 중)은 `--drag-dx`만 바꿔 렌더하지 않으므로 부담이 없는지 코드로 확인.
- **`document.fonts.load`의 글꼴 목록:** `--font-display`에는 Pretendard가 대체로 들어 있다. 제목 글자로 Pretendard 조각까지 받는지는 문제가 되지 않는다(작음).
- **느린 네트워크에서의 실제 폰트 지연:** MSW 서비스 워커가 요청을 받아서 Playwright로 폰트만 늦출 수 없다. 완료 기준 4는 이벤트를 직접 일으켜 다시 재기 경로를 확인한다.

## 3. 확인 못 한 것

- 실제로 느린 네트워크에서 넘기는 중에 글꼴이 도착하는 경우. MSW 서비스 워커가 요청을 받아 Playwright로 글꼴만 늦출 수 없어서, `loadingdone`을 직접 일으켜 다시 재기 경로만 확인했다(완료 기준 4).
- Safari·Firefox에서 `document.fonts.load`가 `unicode-range` 조각을 같은 방식으로 받는지. Chromium에서만 확인했다.
- 실제 터치 기기, Vercel 미리보기 배포.
